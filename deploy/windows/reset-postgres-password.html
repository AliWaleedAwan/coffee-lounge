Forgot the PostgreSQL password?

You have two ways forward. The first needs no password at all.

Easiest: let Coffee Lounge run its own database

Back in the setup, choose "I don't know the password: run Coffee Lounge's own database" and click Next. Coffee Lounge then keeps its data in its own database beside the existing one. Nothing of the existing PostgreSQL changes, and no password is needed.

Or: reset the password (about 5 minutes)

For whoever looks after this PC. You need an administrator account. Other programs using this PostgreSQL pause for a few seconds twice.

During steps 3 to 5, programs on this PC can log in to PostgreSQL without a password. Do them one after the other, and never skip step 5.

  1. Find the data folder

    Press Windows key + R, type services.msc, press Enter. Double-click postgresql-x64-17. In Path to executable, the folder after -D is the data folder. Usually it is: 
    C:\Program Files\PostgreSQL\17\data
    If yours is different, use your folder wherever the commands below say that one.

  2. Open PowerShell as administrator

    Click Start, type PowerShell, right-click Windows PowerShell and choose Run as administrator. Then keep a copy of the login settings: 
    Copy-Item -Force "C:\Program Files\PostgreSQL\17\data\pg_hba.conf" "C:\Program Files\PostgreSQL\17\data\pg_hba.conf.bak"

  3. Allow logins from this PC without a password, for now

    (Get-Content "C:\Program Files\PostgreSQL\17\data\pg_hba.conf") -replace 'scram-sha-256$','trust' -replace 'md5$','trust' | Set-Content "C:\Program Files\PostgreSQL\17\data\pg_hba.conf" -Encoding ascii; Restart-Service postgresql-x64-17

  4. Choose the new password

    It asks twice. Nothing shows while you type. 
    & "C:\Program Files\PostgreSQL\17\bin\psql.exe" -U postgres -h 127.0.0.1 -c "\password postgres"

  5. Put the login settings back: do not skip this

    Copy-Item -Force "C:\Program Files\PostgreSQL\17\data\pg_hba.conf.bak" "C:\Program Files\PostgreSQL\17\data\pg_hba.conf"; Restart-Service postgresql-x64-17

  6. Check that a password is needed again

    This must ask for a password. Press Ctrl+C to leave it. 
    & "C:\Program Files\PostgreSQL\17\bin\psql.exe" -U postgres -h 127.0.0.1 -c "SELECT 1"

  7. Back to the setup

    Choose "Use it", type the new password and click Next. Write the password down and keep it safe: other programs on this PC that used the old one need the new one too.
